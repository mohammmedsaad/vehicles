#  Vehicles

Website for Vehicles car and bike dealership.

## Features
- **Vehicle Catalog**: Fast, responsive showcase for cars, bikes, and SUVs.
- **Dealership Portal**: Dedicated admin panel for managing vehicle inventory, reservations, customer leads, and dealership settings.
- **Modern Tech Stack**: Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS, Motion, and Firebase Firestore.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local` and configure your credentials:
```bash
cp .env.example .env.local
```
Fill in your Firebase project configuration and Cloudflare R2 storage credentials.

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
